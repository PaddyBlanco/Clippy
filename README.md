# 📎 Clippy

> „Schaut aus, ois dadst a README lesn. Brauchst a Hüf dabei?“

A kloans Kastl (M5Stack CoreS3), des ausschaut wia Windows 98, und drin wohnt a Büroklammer,
de ungfrogt ihr Meinung sogt. Sie sitzt am Desktop, schaut deim Coding-Agent bei da Arbeit zua
und wird grantig, wannst as schüttelst.

## Wos kann des?

- **Schaut da beim Programmiern zua.** Claude Code oder Codex denkt noch: sie denkt mit.
  Da Agent braucht a Freigab: sie winkt. Da Agent is fertig: sie gfreit si. Mehr ois du wahrscheinlich.
- **Gspiat ois.** Schütteln, kippen, antippen, Liacht aus, laut sei. Sie merkt's und hot a Meinung dazua.
- **Apps per Commit.** Neiche App ins Repo, kurz wartn, scho is am Gerät. Koa Kabel, koa Flashen.
- **Stürzt stilecht ab.** Hot a App an Fehler, gibt's an Bluescreen. Wia friara.
