Mit dem PC verbinden

Damit die Klammer sieht, was Claude Code, Codex oder GitHub Copilot am PC tun, muss der Agent ihr Bescheid geben. Das richtet der Agent selbst ein. Du brauchst nur einen Satz.

In drei Schritten

  1. WLAN: Am Gerät Startmenü → WLAN einrichten → „Mit Handy“. Clippy muss im selben WLAN sein wie der PC.
  2. Satz eintippen: Diesen Satz in Claude Code, Codex oder Copilot eintippen oder hineinkopieren (Clippy zeigt ihn auch unter Startmenü → „Mit PC verbinden“):

    Richte Clippy ein: paddyblanco.github.io/Clippy/verbinden.txt

  3. Bestätigen: Der Agent liest die Anleitung, zeigt dir, was er einträgt, und fragt nach. Danach schickt er eine Probe: Die Klammer springt vor Freude. Zum Schluss den Agent einmal neu starten.

Hast du mehrere Agents, den Satz einfach in jedem einmal eintippen. Kann Clippy später Neues (wie das Fenster „Agent-Nutzung“), den Satz einfach noch einmal eintippen; der Agent bringt seine Einträge dann auf den neuen Stand.

Was dabei passiert

Der Agent trägt in seine Einstellungen kleine „Hooks“ ein. Das sind Befehle, die er bei jeder Anfrage, jeder Rückfrage und am Ende seiner Antwort ausführt. Jeder Hook schickt mit dem Programm curl eine kurze Nachricht an Clippy. Curl ist in Windows 10/11 schon eingebaut; installiert wird nichts. Clippy unterstützt am PC nur Windows. Ist Clippy aus, merkt der Agent davon nichts.

Die Anleitung für den Agent ist öffentlich und lesbar: verbinden.txt.

Wieder entfernen

Sag deinem Agent: Entferne alle Hooks, die an clippy.local schicken.
